## 🧠 Why This Repository Exists

AI assistants can be extremely useful for security research and software development.

But the quality of the result often depends heavily on **how the task is presented to the AI**.

For example:

> "Find vulnerabilities in this code."

can produce a very different result from a structured prompt that tells the AI:

* What to analyze
* How deeply to investigate
* What assumptions to question
* How to trace data and logic
* What types of issues to look for
* How findings should be validated
* How results should be reported

The prompts in this repository are built around that idea.

**Better instructions → better analysis → better results.**
